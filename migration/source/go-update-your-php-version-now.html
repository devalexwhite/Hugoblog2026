Go update your PHP version now!

October 21, 2026  |  1 min read

If you're running a blog that is built on PHP (for example, Pure Blog), you need to update your PHP installation right now. Critical vulnerabilities have been discovered in PHP, putting any PHP application at risk.

So SSH into your server, run sudo apt update && sudo apt upgrade && sudo reboot now and then run php -v to ensure you are now running one of the patched versions (8.5.12, 8.4.27, 8.3.36 and 8.2.35).

Don't delay, act today!
